# Audiobird v0.2.16-esp32lite 完整引脚接线说明

适用：固件 v0.2.16（及 v0.2.10 之后各版），目标板
**「MicroPython ESP32 开发板 V1.0 Rev1」**（LOLIN32 Lite 版型克隆板：
裸 ESP32 + PCB 天线、CH340、JST 锂电座、只有 RST 键、**无 BOOT 键、
GPIO21 未引出**）。烧录选 ESP32 Dev Module，**Core 必须 2.0.17**。

> 本说明为准绳：以下引脚是固件写死的，配置网页改不了。
> 旧 README 里的接线表仍可参考，但其中「L/R 选左声道、固件按
> ONLY_LEFT 读取」的说法是 v0.2.10 之前的旧机制，已过时——
> 以本文为准。用 v0.3.4 PCB 打板的用户按 PCB 丝印与 NETLIST 接，
> 不用飞线，本文针对开发板面包板 / 洞洞板搭建。

## 1. INMP441 数字麦克风模块（I2S）

| INMP441 引脚 | 接到 |
|---|---|
| VDD | 3V3（供电 1.8–3.3V，只能用 3V3） |
| GND | GND |
| SCK | GPIO14 |
| WS | GPIO27 |
| SD | GPIO26 |
| L/R | **GND** |

**关键说明（v0.2.10 起的实测结论，不要“纠正”它）：**
实测中 L/R 接 GND 时，数据出现在 I2S 的**右声道时隙**（左声道时隙
全 0），因此固件 v0.2.10 起改读 `I2S_CHANNEL_FMT_ONLY_RIGHT`，
录音正常。**不要把 L/R 改接 3V3**——那样数据会跑到左声道时隙，
而固件只读右声道，结果就是再次无声（v0.2.9 的全 0 静音就是这么
查出来的）。接线以“能录出声”为准，不以数据手册的字面声道为准。

## 2. MicroSD / TF 卡模块（SPI）

| SD 模块引脚 | 接到 |
|---|---|
| VCC | 3V3（裸模块 / 带稳压的模块均可 3V3 供电，个别 5V 专用模块除外） |
| GND | GND |
| SCK | GPIO18 |
| MISO | GPIO19 |
| MOSI | GPIO23 |
| CS | GPIO5 |

- SPI 速率 4 MHz（固件写死）。
- 卡要求 **FAT32**：本 Core 的 FatFs 关了 exFAT，exFAT 卡挂不上；
  这种卡可用 v0.2.15 起的网页「格式化 TF 卡」功能格成 FAT32。
- 录音以 `ABIRD_XXXX.WAV` 顺序写入根目录；索引写根目录
  `ABIRD_LOG.CSV`；配置写根目录 `CONFIG.TXT`。
- 旧卡文件系统损坏时，开机扫描可能卡几十秒——备份录音后整卡
  FAT32 重格即可（v0.2.15 起也可网页格式化）。

## 3. DS3231 时钟模块（I2C，可选但强烈建议）

| DS3231 引脚 | 接到 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | **GPIO33** |
| SCL | **GPIO32** |
| SQW / 32K | 不接（固件不用） |

- **不要按 DevKit 教程接 21/22：此板 GPIO21 根本没有引出**，
  GPIO22 是板载蓝 LED。ESP32 的 I2C 可映射到任意引脚，固件用 33/32。
- 不接 DS3231 也能跑：靠软件时钟 + 配置页「用手机时间同步」顶着，
  但软件时钟每天漂移几分钟，且断电后时间丢失；涉及录音时刻的分析
  （如晨昏鸣叫规律）务必接上，并用配置页对时校准一次。

## 4. 板载资源（已在板上，不要重复接线）

| 资源 | 引脚 | 说明 |
|---|---|---|
| 蓝色 LED | GPIO22 | 低电平点亮；录音时闪烁、配置模式常亮 |
| 电池电压分压 | GPIO35 | JST 电池经板载 100k/100k 分压接入，固件读数 ×2 还原 |
| JST 锂电座 | — | 3.7V 锂电池（注意正负极方向）；插 USB 时板载自动充电 |
| RST 键 | — | 板上唯一的按键；按一下 = 上电复位 |
| CH340 USB 口 | — | 供电 + 烧录 + 串口日志（115200）三合一 |

**电池未接时**：USB 供电下 GPIO35 悬空，配置页电量读数
（如 284 mV / 2866 mV 跳变）是悬空 ADC 噪声，**不是故障**。

## 5. 供电

| 方式 | 说明 |
|---|---|
| USB（CH340 口） | 供电 + 烧录 + 串口日志三合一 |
| JST 锂电池座 | 3.7V 锂电池；插 USB 时板载自动充电 |
| 野外部署 | 电池供电即可；太阳能等外部电源接 USB 口或 JST 输入 |

**所有模块必须共地；INMP441、SD、DS3231 一律用 3V3，不要给
任何 IO 脚接 5V。**

## 6. 进配置模式（v0.2.16 的行为）

- **上电 / 按 RST 键 = 默认进配置模式**：直接开热点，手机连
  `AUDIOBIRD-01-XXXX`（密码 `audiobird`），连上自动弹出配置页，
  未弹出时浏览器打开 http://192.168.4.1 。
- 深睡唤醒、软件重启 → 直接进工作模式（不会卡配置循环）。
- 另一条免按键的路：SD 卡插电脑，在根目录 `CONFIG.TXT` 里写一行
  `FORCE_CONFIG=1`，插回上电即进配置（固件进模式后自动清掉该标志）。
- **GPIO0（丝印「0」）在 v0.2.16 不再用作配置触发**（5 秒窗口已删除）。
  只有一条铁律：**上电瞬间绝不能把 GPIO0 短接到 GND**——那是芯片的
  ROM 下载模式，固件不会启动。

配置态另有两个自动退出：2 分钟无 Wi-Fi 客户端接入自动重启回工作
模式（有人连上过则永久取消）；5 分钟无操作定时器。

## 7. 上电前检查清单

- [ ] INMP441：14 / 27 / 26 / L/R→GND / 3V3，共地
- [ ] SD 模块：18 / 19 / 23 / 5 / 3V3，卡已 FAT32 格式化
- [ ] DS3231（如接）：33 / 32 / 3V3；不接则记住时间靠手机同步
- [ ] 没有任何线接到 GPIO21（不存在）、GPIO6–11（内部 Flash）、GPIO1/3（串口）
- [ ] GPIO0 上电时悬空，没有短接
- [ ] 全部模块共地，没有 5V 进 IO 脚

## 8. 常见接错

| 现象 | 最可能的原因 |
|---|---|
| 录音文件全 0 静音 | L/R 被改接 3V3（应接 GND，固件读右声道）；或 SD/DIN 线接错 |
| 上电串口显示 `boot:0x3 (DOWNLOAD_BOOT)` | 上电瞬间 GPIO0 被短接，松开后重新上电 |
| 时间每天差几分钟 / 断电后时间丢 | 没接 DS3231，软件时钟漂移；接上并对时一次 |
| SD 卡挂不上 / 开机扫描卡很久 | exFAT 卡或文件系统损坏，FAT32 重格（可用网页格式化） |
| 配置页电量读数乱跳 | 电池没接、USB 供电，GPIO35 悬空噪声，不是故障 |
| DS3231 找不到设备 | 接到了 21/22（此板没有 21）；改接 33/32 |

## v0.2.24 说明

- DS3231 为可选项：不接也能记录时间（走手机同步的软件时钟），
  但彻底断电会丢时间；要断电不丢时间请接 DS3231。
- v0.2.24 修掉了 v0.2.21 的误判：没接 DS3231 时悬空 I2C 引脚
  可能被误判为有 RTC，导致录音全是 unix=0。
