# Audiobird 硬件说明

## v0.1: 模块堆叠方案 (无需画 PCB)

v0.1 直接用现成模组杜邦线连接, 目标是**先跑通录音闭环**,
验证通过后再做一体化 PCB (见文末 v0.2)。

### 原理框图

```
  18650电池 --[充放电保护板]--+-- 3.3V稳压 --> ESP32-S3-WROOM-1 模组
                              +-- 3.3V      --> INMP441 麦克风模块
                              +-- 3.3V      --> MicroSD 模块
                              +-- 3.3V      --> DS3231 RTC 模块(可选)

  ESP32-S3  <--I2S-->  INMP441 (GPIO 4/5/6)
  ESP32-S3  <--SPI-->  MicroSD (GPIO 10/11/12/13)
  ESP32-S3  <--I2C-->  DS3231  (GPIO 8/9, 可选, v0.2)
```

### 供电说明

- 野外部署推荐 18650 + 太阳能板 (5V 1A) + TP4056 充电, 可长期免维护
- 仅验证阶段可用 3xAA 电池盒 (需确认开发板支持 5V 输入, 多数 S3 开发板 Type-C 口可直接供 5V)
- 注意: SD 卡写入瞬间电流较大, 电源内阻大时可能复位, 电池电量低时先换电池再排查

### 野外部署建议

- 麦克风朝下或加防风罩 (海绵), 避免风噪淹没鸟声
- 设备装防水盒, 麦克风开孔处贴防水透气膜
- 先做 48 小时连续测试再长期布设

## v0.2: 一体化 PCB 设计要点 (规划中)

- 主控: ESP32-S3-WROOM-1 模组 (邮票孔, 免画射频部分)
- 麦克风: ICS-43434 或 INMP441 (I2S, 注意 L/R 选择)
- 存储: MicroSD 卡座, SPI 模式, 走线尽量短
- 电源: TP4056 充电 + DW01 保护 + 3.3V LDO (如 ME6211), 太阳能输入预留
- 时钟: DS3231M (内置晶振, 省空间) 或依赖 WiFi NTP
- 绘制工具: 嘉立创EDA专业版, 按本目录接线总表画原理图即可
- 打板: 嘉立创 2层板, 5片起 (流程见固件 README 故障排查外的说明, 下单参数 1.6mm/1oz/无铅喷锡)
