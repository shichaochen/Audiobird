# Audiobird App 设计文档

> 版本: v0.2 草案 | 状态: 设计中
> 配套固件: v0.2 (本仓库 firmware/) | 配套硬件: v0.1 模块版 + v0.2 增补 (DS3231、电量检测)

## 1. 定位与原则

Audiobird App 是 Audiobird 设备的自研配置与管理工具, 对应 AudioMoth 生态中
Configuration App + Time App + 文件管理的角色, 但**只为 Audiobird 硬件服务,
不兼容 AudioMoth 的 USB 协议** (决策见 2026-10-14 记录)。

设计原则:

- **零安装**: ESP32-S3 开 AP 热点, 手机浏览器打开即用, 不装原生 App。
  需要时可打包成 PWA (添加到主屏幕)。
- **手机端优先**: 页面按手机屏幕设计, 大按钮、滑杆, 电脑浏览器同样可用。
- **配置落盘**: 所有配置写入 SD 卡 `CONFIG.TXT`, 与固件 v0.1 格式兼容,
  断电不丢失, 无 App 时仍可手动改配置。
- **配置与录音互斥**: 配置模式下不录音, 避免 WiFi 功耗与录音干扰;
  工作模式下 WiFi 关闭, 靠 deep sleep 省电。

## 2. 两种工作模式

| 模式 | WiFi | 录音 | 进入方式 |
|---|---|---|---|
| 配置模式 (CONFIG) | AP 开启, 网页 App 可用 | 暂停 | 上电时长按配置键 / `CONFIG.TXT` 中 `FORCE_CONFIG=1` |
| 工作模式 (RECORD) | 关闭 | 按配置循环录音 | 配置保存后重启 / 配置模式 5 分钟无客户端自动退出 |

- 配置模式超时: 5 分钟无客户端连接, 自动回到工作模式 (防止野外误触耗电)。
- 配置保存后设备自动重启进入工作模式。

## 3. 功能模块

### 3.1 仪表盘 (首页)

- 设备名、固件版本
- 电量: 电压 (mV) + 百分比 (粗略映射, 见 §6)
- 存储: SD 卡已用 / 剩余 / 文件数
- 当前配置摘要 (采样率、增益、录制/休眠时长、时间表)
- 最近一次录音文件名与时间

### 3.2 配置页

| 参数 | 取值 | 说明 |
|---|---|---|
| 采样率 | 8000 / 16000 / 32000 / 48000 Hz | 默认 32000 |
| 数字增益 | 1–32 | 默认 4 |
| 录制时长 | 10–3600 秒 | 默认 60 |
| 休眠间隔 | 0–86400 秒 | 默认 300; 0 = 连续录制 |
| 录制时间表 | 时段列表, 如 `05:00-08:00,17:00-19:00` | 为空 = 全天; 需固件 v0.2 支持 |
| 幅度触发 | 开/关 + 阈值 | v0.3, 预留字段 |
| 设备名 | 文本 | 默认 `Audiobird-01`, 用于 AP 名称与文件前缀 |

### 3.3 对时

- 手机时间一键同步 (页面按钮, 取手机当前时间)
- 手动输入时间
- 若设备连入家庭 WiFi (v0.3), 可用 NTP 对时
- 对时后写入 DS3231 RTC (v0.2 硬件), 断电后时间不丢

### 3.4 文件管理

- 列表: 文件名、大小、估算时长 (由文件大小 / 采样率 / 位深推算)
- 下载: 单个文件下载 (支持断点续传 Range, 可选)
- 删除: 单个删除; 全部删除需二次确认
- 格式化 SD 卡: 危险操作, 二次确认 + 输入 `FORMAT` 确认
- 文件命名: 延续固件规则 `ABIRD_XXXX.WAV`, 断电续写不重名
  (固件 `resolveFileIndex()` 扫描已有文件取最大序号 +1)

### 3.5 固件升级 (OTA)

- 上传 `.bin` 文件 → 校验 → 写入 → 重启
- 升级失败保留旧固件可启动 (利用 ESP32 双 OTA 分区, v0.3)
- 升级过程页面显示进度, 升级后显示新版本号

### 3.6 系统

- 恢复默认配置
- 重启设备
- 查看运行日志 (最近 N 行串口日志镜像)
- 导出配置 (下载当前 `CONFIG.TXT`)

## 4. 通信接口 (HTTP API)

网页 App 通过以下接口与固件通信, 全部为局域网 HTTP (AP 模式下 `http://192.168.4.1`)。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 设备状态: 设备名、固件版本、电量、存储、文件数、配置摘要 |
| GET | `/api/config` | 读取当前配置 |
| POST | `/api/config` | 保存配置 (JSON, 见 §5), 写入 `CONFIG.TXT` |
| POST | `/api/time` | 对时 `{ "unix": 1730000000 }` |
| GET | `/api/files` | 文件列表 `[{name, size, duration_est}]` |
| GET | `/api/files/<name>` | 下载单个文件 |
| DELETE | `/api/files/<name>` | 删除单个文件 |
| POST | `/api/firmware` | 上传 `.bin` (multipart), OTA 升级 |
| POST | `/api/reboot` | 重启设备 |
| POST | `/api/format` | 格式化 SD 卡 (需 `{"confirm":"FORMAT"}`) |
| GET | `/api/log` | 最近日志 |

## 5. CONFIG.TXT 格式 (v0.2 扩展, 向后兼容 v0.1)

```
# Audiobird 配置文件 (v0.2)
SAMPLE_RATE=32000
RECORD_SECONDS=60
SLEEP_SECONDS=300
GAIN=4
SCHEDULE=05:00-08:00,17:00-19:00
DEVICE_NAME=Audiobird-01
FORCE_CONFIG=0
```

- v0.1 固件忽略不认识的字段, 新旧版本可混用同一张卡。
- 固件读取 `SCHEDULE` 后, 仅在时段内录音, 时段外 deep sleep。
- `FORCE_CONFIG=1` 用于"下次启动进配置模式", App 保存配置后自动清零。

- [ ] 配置模式进入/退出逻辑 + 5 分钟超时
- [ ] `CONFIG.TXT` 读写 + `SCHEDULE` 解析
- [ ] DS3231 RTC 驱动 (I2C, GPIO 8/9) + 对时接口
- [ ] 电量检测: 电池经分压电阻接 ADC, 粗略映射百分比
      (18650: 4.2V=100%, 3.7V≈50%, 3.3V≈5%; 仅作参考, 勿作精确电量计)
- [ ] OTA 升级 (`Update` 库)
- [ ] 文件下载 / 删除 / 格式化接口

## 7. 前端实现

- **单文件 HTML**: HTML + CSS + JS 内嵌于一个文件, 存入 LittleFS,
  避免多文件部署与路径问题。
- **零框架**: 原生 JS + `fetch()` 调用 §4 API, 不引入 Vue/React, 保持固件体积小。
- **移动端优先**: 响应式布局, 触控友好的滑杆与按钮。
- **PWA (v0.3)**: 增加 manifest + Service Worker, 可"添加到主屏幕"像原生 App 使用。

## 8. 安全

- AP 默认密码 `audiobird`, 首次使用在 App 首页提醒修改 (v0.3 支持自定义密码)。
- 格式化 SD 卡、固件升级必须二次确认。
- 设备仅局域网可达, 不暴露公网; 不收集任何个人信息。

## 9. 开发计划

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| 阶段 1 | 状态页 + 配置页 + 对时 | 配置保存后断电重启仍生效 |
| 阶段 2 | 文件管理 (列表/下载/删除) | 手机能下载一个 WAV 并播放 |
| 阶段 3 | OTA + 格式化 + PWA | 固件可通过网页升级, 失败可回退 |

## 10. 测试清单

- [ ] 配置保存 → 断电 → 重启 → 配置仍生效, 录音参数正确
- [ ] 配置模式 5 分钟无操作 → 自动回工作模式并开始录音
- [ ] SD 卡满时 App 显示警告, 固件不崩溃
- [ ] 格式化需二次确认, 误触不会执行
- [ ] OTA 上传错误文件 (.txt 等) 被拒绝, 设备可正常重启
- [ ] 手机端 (iOS Safari / Android Chrome) 页面布局正常

## 11. 与现有系统关系

- **与 v0.1 固件**: `CONFIG.TXT` 格式延续, 新增字段向后兼容。
- **与 AudioMoth 生态**: 不兼容其 USB App, 自研生态; WAV 文件仍可直接用于 BirdNET / Kaleidoscope 等分析工具。
- **与课题申报框架**: App 对应申报框架"边缘端部署"与"预期成果"中的设备配套软件部分。
